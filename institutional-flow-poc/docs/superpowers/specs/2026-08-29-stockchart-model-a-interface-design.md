# StockChart Model A 介面設計規格

最後更新：2026-08-29

## 1. 設計摘要

StockChart 目前是可重跑、可核對的法人流量資料觀察工具。本規格借鑑 Tide 的「今日入口、分類視覺、逐層深入」體驗，但只採用 Model A，不引入 Model B、AI 摘要、投票、預測或交易訊號。

Model A 固定定義如下：

- X 軸：5D Flow
- Y 軸：1D Flow
- 原點：零流量
- 象限：只作座標分類，不轉譯成看多、看空或推薦
- trail：依日期重建最近 5D／10D／20D 的歷史移動

## 2. 目標與非目標

### 目標

1. 讓使用者在 30 秒內知道最新交易日是否完整，以及資料是否可用。
2. 讓使用者從產業總覽進入 Model A，再追到法人組合與可核對的資料列。
3. 同一畫面保留資料來源、品質狀態、basis 與 generated_at 的可追溯線索。
4. 讓外資、投信、自營商、combined、all 與自由組合可在同一套介面切換。

### 非目標

- 不做 Model B 或 A/B 模型比較。
- 不新增 AI、新聞、即時行情、買賣訊號、預測機率或投資建議。
- 不把象限名稱包裝成投資語意。
- 不改變既有 shares／amount 計算定義與資料品質規則。

## 3. 導航與資訊架構

採用 Tide 手機版的五分頁概念，但將內容改為符合 StockChart 的 observation-only 語意：

1. **今日觀察**：最新快照、完整性、法人差異與品質提示。
2. **Model A**：5D Flow × 1D Flow 的 Rotation Map 與 trail。
3. **法人排行**：依 Flow、Breadth、集中度查看產業資料。
4. **追蹤產業**：使用者收藏的產業與歷史觀察，無推測性通知。
5. **資料品質**：來源、缺漏、算術檢查、期間與 manifest。

桌面版可將五分頁轉為側邊導航；行動版使用底部導航。導航切換不應改變已選定的日期、法人組合與 basis，除非使用者主動重設。

## 4. 今日觀察首頁

首頁模組依序如下：

### 4.1 資料狀態列

顯示：

- 最新交易日
- 需求天數／有效交易日數（例如 120／120）
- basis：shares 或 amount
- 品質狀態：通過、部分缺漏或需檢查
- `generated_at`

若來源延遲或交易日不足，狀態列必須在視覺層級上高於任何圖表。

### 4.2 最新產業觀察

顯示最新日的產業卡片，欄位至少包含 Flow 1D、Flow 5D、Flow 20D、Breadth 與 stock_count。卡片只使用中性描述，例如「5D Flow 最大」「Breadth 較廣」，不使用「強勢」「看多」等推論語意。

### 4.3 法人組合比較

提供 foreign、trust、dealer、combined、all 與自由組合切換。切換後保留同一排序與欄位，避免使用者把不同分母誤認為同一指標。

### 4.4 Model A 預覽

顯示固定 Model A 的小型 Rotation Map；點擊產業卡片後進入完整 Model A 頁面。預覽必須標示 `X=5D Flow`、`Y=1D Flow` 與 basis。

## 5. Model A 頁面

### 5.1 控制列

- 法人組合選擇器
- 日期或最新日選擇器
- basis 選擇器
- trail 視窗：5D、10D、20D
- CSV 下載入口

控制列的每次變更都應同步更新圖表、表格與 metadata，不允許只更新其中一個視圖。

### 5.2 圖表

- X 軸為 5D Flow，Y 軸為 1D Flow。
- 原點與軸線清楚可見。
- 象限標籤限定為資料座標分類，例如 `ACCUMULATING`、`WEAKENING`、`REVERSING`、`DISTRIBUTING`。
- 點大小可表達資料量，但必須在圖例明確說明。
- 點標籤不可因截斷而失去產業辨識；空間不足時改由 tooltip 或側邊詳情呈現。
- trail 以日期順序連線，不以線段顏色暗示未來方向。

### 5.3 產業詳情

點擊產業後顯示：

- 產業名稱與代碼
- Model A 座標
- Flow 1D／5D／20D
- Breadth、Top1／Top3 concentration、stock_count
- 法人組合與 basis
- 來源日期與資料品質狀態
- 最近 5D／10D／20D trail 的表格化資料

## 6. 法人排行

排行提供固定的資料視角：

- Flow
- Breadth
- Top1 concentration
- Top3 concentration
- stock_count

支援當日與 5D／20D 視窗，但不新增「推薦排序」或預測分數。每列應同時呈現數值、單位、期間與法人組合。

## 7. 追蹤產業

追蹤清單提供收藏產業的最新快照與歷史變化。空狀態可提供依資料排序的可加入產業清單，但不使用「推薦」字樣，也不得寫成投資建議。

第一版不做推播；若未來加入通知，通知內容只能描述資料更新或品質異常，不能描述買賣方向。

## 8. 資料品質與錯誤狀態

所有頁面都要能回到同一份品質摘要：

- complete trading days
- market／flow row count
- duplicate
- arithmetic failure
- missing symbol
- source URL
- `generated_at`
- SHA-256

錯誤狀態分三級：

1. **可用**：資料完整，正常顯示。
2. **部分可用**：有缺漏，圖表照顯示但在標題與表格標示範圍。
3. **不可用**：無法形成有效視窗，停用圖表並提供可核對的失敗原因。

## 9. 可及性與互動規則

- 每頁一個 `h1`，內容區使用有順序的 `h2`／`h3`。
- 所有圖表控制項有可讀名稱；圖示按鈕不得只依賴圖示或顏色。
- 顏色不是唯一資訊來源；象限與品質狀態需同時有文字。
- 鍵盤可依序通過日期、法人組合、basis、trail、圖表詳情與下載入口。
- 文字放大與窄螢幕重排不可讓圖表標籤或品質警示消失。
- 不以 hover 作為唯一取得數值的方法。

## 10. 驗收條件

- 介面只出現 Model A，且所有文案明確寫出 `5D Flow × 1D Flow`。
- 法人組合與 basis 切換會同步更新 Map、排行、詳情與 metadata。
- 每一個可見數值都能追溯到對應輸出 CSV／JSON。
- 缺漏、算術失敗與日期不足不會被零值或空白掩蓋。
- 不出現 AI、看多／看空、預測機率、明牌、推薦或交易訊號語意。
- 桌面與手機版都保留資料品質與來源入口。

## 11. 實作順序建議

1. 先把現有 CSV／JSON 輸出包成 Model A 的單一資料契約。
2. 建立今日觀察與 Model A 兩個核心畫面。
3. 加入法人組合、basis、日期與 trail 控制列。
4. 再加入排行、追蹤產業與資料品質分頁。
5. 最後做桌面／手機響應式與鍵盤可及性驗證。
