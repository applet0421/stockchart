# Tide 潮汐網站參考分析

- 稽核日期：2026-08-29
- 範圍：公開首頁、新手導覽、泡泡圖主儀表板、個股搜尋與詳情、方案與定價頁
- 目標：評估產品定位、資訊架構、互動、轉換與可及性風險

## 總評

Tide 的最大優勢是定位鮮明：不試圖成為全功能看盤軟體，而是把「法人資金往哪裡移動」濃縮成潮汐分類、泡泡圖與白話盤後摘要。產品記憶點強，資料來源、免責、免費與 Pro 邊界也交代清楚。

主要問題不是功能不足，而是首訪干擾與資訊密度。新手一進站同時面對導覽、圖表、觀察清單、投票與多個工具入口；退出導覽後又疊出推播提示，延後了使用者第一次真正操作圖表的時間。

## 走查步驟

1. 首次進站 — 健康度：普通
   - 歡迎文案很快說清楚價值與使用時間成本。
   - 背景資訊量大，導覽框、泡泡圖、側欄與頂部工具彼此競爭注意力。

2. 今日重點導覽 — 健康度：良好
   - 把最簡單的入口先教給新手，符合「先讀摘要、再看圖」的學習順序。
   - 導覽共多步，缺少清楚的「剩餘幾步」文字，只能從圓點猜進度。

3. 泡泡圖教學 — 健康度：良好
   - 左右、上下、大小與顏色的映射說明完整，並直接框出對應區域。
   - 文案一次塞入五條規則，首次理解成本仍偏高；可拆成圖上標註或逐條示範。

4. 關閉導覽／主畫面 — 健康度：偏弱
   - 關閉後立即出現推播提示，並遮住已展開的今日重點，形成雙層干擾。
   - 建議把推播邀請延後到使用者完成一次搜尋、加入自選或第二次回訪。

5. 乾淨儀表板 — 健康度：良好
   - 「漲潮／輪動／觀望／退潮」與象限位置形成一套一致語言，辨識度高。
   - 圖內縮寫與泡泡互相遮擋，部分文字被截斷；首次使用者需依賴 hover 才能判讀。

6. 搜尋個股 — 健康度：良好
   - 搜尋框位於頂部核心位置，輸入代碼後即時給出個股與相關板塊結果。
   - 個股與板塊混在同一列時，類型差異只靠文字內容判斷，可加「個股／板塊」標籤。

7. 個股詳情 — 健康度：良好
   - 先顯示代碼、名稱、題材標籤與 30 日趨勢，再進入法人買賣超，層級合理。
   - 卡片內容需要垂直捲動，但底部「籌碼提醒／加入自選」固定欄會壓縮可讀高度。

8. 方案與定價 — 健康度：良好
   - 年繳、月繳、退款、取消、ATM 與金流責任交代清楚，能降低金融產品的信任門檻。
   - 首屏之後內容很長，免費與 Pro 差異、定位與免責多次重複；可用比較表與摺疊 FAQ 減少閱讀負擔。

## 最值得借鏡

1. 用一個具象隱喻統一資料語言：潮汐、漲潮、退潮、資金流入與流出彼此一致。
2. 把複雜分析轉成「今日重點 → 圖表 → 個股詳情」三層漸進揭露。
3. 免費版不是殘缺試用版，Pro 販售的是分析深度；價值邊界容易理解。
4. 金融信任資訊放在關鍵決策附近：資料日期、來源、免責、退款與取消都能找到。
5. 空白觀察清單不只顯示空狀態，也提供當日法人買超候選，直接帶動下一個動作。

## 高優先改善

1. 首訪只保留一個主動引導；導覽結束後不要立刻再推推播。
2. 讓使用者先完成一次「搜尋 → 看詳情」的小成功，再邀請登入、通知或訂閱。
3. 為搜尋結果加類型標籤，並降低泡泡名稱截斷與遮擋。
4. 補上真正的頁面標題階層。首頁 DOM 未發現 h1–h6，對讀屏導覽與內容結構不利。
5. 修正無可及名稱的互動按鈕；本次檢查發現可見詳情區仍有空白名稱按鈕風險。
6. 對鍵盤、焦點順序、縮放重排與色彩對比做專門測試；本次截圖與 DOM 走查不足以宣稱 WCAG 合規。

## 登入後體驗補充

登入狀態顯示為免費版，且已建立個人化「我的」分頁。這讓產品閉環更完整：今日摘要負責回訪、泡泡圖負責探索、排行負責比較、自選股負責留存、我的分頁負責會員與設定。

- 今日總覽：情緒 51 中性、法人買最多、異常個股、AI 盤後總結、明日多空投票與近 5 日漲潮板塊集中在單頁，日常閱讀效率高。
- 板塊排行榜：提供法人動向／買多漲少／逆勢買超／個股異常／外資投信等分類，並可切換買超／賣超與當日／5 日，篩選模型清楚。
- 自選股：0 檔時仍提供法人買超候選，空狀態不是死路；但「我的清單」與右下角新增按鈕功能重複，可考慮只保留一個主入口。
- 我的分頁：帳號狀態、連續打卡、監控、勝率、設定、教學、分享與社群入口集中，會員狀態容易找到。
- Pro 轉換：免費會員點擊「看外資、投信各自買了什麼」後進入會員狀態頁，再以單一「看方案與價格」CTA 轉去定價，路徑乾淨且沒有立即付款壓力。

登入後的主要風險是「產品入口很多，但主線沒有被明確排序」：今日、泡泡圖、排行都能成為第一入口；對新用戶來說，可用首次登入後固定導向今日總覽，讓其他分頁成為探索而非競爭入口。
